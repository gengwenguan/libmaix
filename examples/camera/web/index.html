    AI 人形识别（自动拍照）
    范围 0.10~0.95；越大越严格，误检越少
    同一时段内连续触发的最小冷却时间
    NPU 每秒推理帧数；越大越灵敏越费电
    模型文件需手动放到开发板 /root/models/： awnn_yolo_person.bin + awnn_yolo_person.param。 缺失则人形识别不可用，但其它功能不受影响。
    移动侦测 VMD（与 AI 平行；纯 CPU 帧差）
    单像素 luma 差 > 此值才计入"变化"；25 适合室内
    变化像素占画面比例 > 此值才触发；默认 0.021 = 2.1%
    默认 2 秒：同一段移动期内每 2s 拍一张
    CPU 每秒做几次帧差；5 已足够灵敏
    与 AI 检测可同时开启：白天用 AI 精确识别"人"，夜间或断网时用 VMD 兜底。 完全在板端 CPU 上跑（80×60 下采样后差分），开销 < 50us/帧，对 30Hz 主循环无影响。
    录像
    关闭后停止写入新录像，不影响直播和已有文件
    默认 600 = 10 分钟；下次切片才生效
    超出按 mtime 删最早；与"保留天数"双兜底
    相册（手动 + 自动拍照共用）
    超出时按 mtime 删最早
    麦克风滤波
    保存后即时生效；推荐先用“均衡推荐”
    这些模式来自后 25 秒安静样本分析：主噪声为 50Hz 附近电流声及倍频。 模式越激进越安静，但人声低频会越薄；噪声门在静音时最干净，可能有开关门感。
    OSD（视频上叠加文字）
    仅在 AI 检测开启时生效
    补光灯（外接 LED，GPIO 控制）
    关闭时确保灯灭
    声控：时段内有声音才亮，持续一段时间
    0~23；支持跨零点（如 18→6 表示傍晚到清晨）；起=止表示全天
    0~100；数值越低越敏感，可按 1 精细调整
    声控触发后持续点亮的时长；期间再有声音会续期
    PH13=237（默认，推荐）；PH14=238 与板载 State LED 共用
    默认高电平点亮；灯板逻辑相反时勾选
    GPIO 仅输出 3.3V 控制信号到灯板 DO，灯板需另接 5V 供电并与开发板共地。 时段按北京时间（UTC+8）判定；声控响度取自麦克风采集，无需额外接线。
    camera-hub 远端连接
    未连接
    推荐使用 DDNS 域名；标准 HTTP 80 无需端口
    仅用于 IPv6 字面量；使用 DDNS 域名时无需勾选
    URL 非空时自动建立单条 WebSocket 并上传媒体；清空 URL 即停止连接。 AI 与远端录像请在 camera-hub Web 中配置。
    MQTT IPv6 上报（公网 IPv6 变化时推送）
    域名 / IPv4 / IPv6 均可
    明文 MQTT 通常 1883
    payload 为纯 IPv6 字符串
    同 broker 下多设备需区分
    检测网卡 IPv6 变化的间隔；默认 10
    取该网卡的全局 IPv6（排除 fe80:: / ::1）
    地址没变也每隔此秒数重报一次（心跳）；默认 3600=1小时；0=关闭仅变化时报
    开启后新订阅者一连上即收到最后上报的地址；推荐开启
    常驻后台线程按需短连接：仅当网卡全局 IPv6 相较上次变化时才连 broker 发布一次， publish 完立即断开；地址不变时零网络开销。关闭时线程只空转。
    所有设置即时落盘到 config.json；其中 AI / 相册 / OSD 立即生效， 录像分片时长在下次切片时生效（10 分钟内）。
